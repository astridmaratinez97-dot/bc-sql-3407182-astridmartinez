📄 Semana 01 — Introducción a Bases de Datos

Proyecto correspondiente a la Semana 01 del bootcamp SQL.

📚 Descripción

Durante esta semana se trabajó la comprensión de los conceptos fundamentales de bases de datos relacionales.

Debido a limitaciones de instalación de Docker en el equipo, el ejercicio fue desarrollado utilizando archivos JSON como representación inicial de la información.

Se modelaron entidades relacionadas con el contexto académico del SENA.

⚙️ Actividades realizadas
Representación de información mediante archivos JSON.
Organización de estructuras de datos.
Identificación de entidades y atributos.
Definición de relaciones conceptuales.
Comprensión del modelo relacional.

🧠 Buenas prácticas aplicadas
Uso de nombres descriptivos.
Organización clara de la información.
Estructuración jerárquica de los datos.
Preparación del dominio para migración posterior a SQLite.

⚙️ Tecnologías utilizadas
JSON
Git
GitHub

📌 Nota

Esta semana permitió comprender la estructura de los datos antes de iniciar la implementación en SQL y SQLite.
