# Week 03 — DML: Manipulación de Datos

Proyecto de la Semana 03 del bootcamp SQL usando SQLite.

## 📚 Descripción

Este proyecto implementa operaciones DML sobre un sistema académico del SENA.

Se trabajó con las tablas:

- apprentices
- programs
- enrollments

El proyecto incluye:

- INSERT INTO
- UPDATE
- DELETE
- FOREIGN KEY
- Constraints
- Datos realistas
